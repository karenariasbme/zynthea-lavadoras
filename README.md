# Demo · Sistema para Lavadoras y Lubricadoras

Demo gratuita del Sistema para Lavadoras y Lubricadoras de **Zynthea Solutions**: stock de aceites y filtros con aviso de stock bajo, cambios de aceite por marca y modelo, galones y cuartos, valor a cobrar y exportación a Excel.

- **Probar la demo:** https://karenariasbme.github.io/zynthea-lavadoras/
- **Planes y precios:** https://karenariasbme.github.io/KarenArias/lavadoras/

## Sobre la demo

- Es una página estática (un solo `index.html`, sin servidor ni base de datos).
- Viene con datos de ejemplo de un "Lubricentro Demo".
- Lo que registras se guarda **solo en tu navegador** (`localStorage`, claves `zlav_demo_`). Nadie más lo ve y no se envía a ningún servidor.
- El botón **Restablecer demo** borra esos datos y vuelve a los de ejemplo.

El sistema que se entrega a cada cliente se configura con sus propios productos, modelos de carros, precios y marca.
